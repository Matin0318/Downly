# Third-party software

Downly is built on open-source libraries. Their licenses allow this use. Please keep this notice when you redistribute the app.

| Library | Used for | License |
|---|---|---|
| Kotlin, kotlinx.coroutines, kotlinx.serialization | Language, concurrency, JSON storage | Apache-2.0 |
| Compose Multiplatform, Jetpack Compose, Material 3 | User interface | Apache-2.0 |
| AndroidX (Core, Activity, WebKit) | Android integration, the built-in browser's proxy support | Apache-2.0 |
| Ktor client | HTTP client | Apache-2.0 |
| OkHttp, Okio | Networking and file access | Apache-2.0 |
| libtorrent4j | BitTorrent for Android | MIT |
| libtorrent | The BitTorrent library inside libtorrent4j | BSD-3-Clause |

The full license texts are in each project's repository.

Downly itself is released under the [MIT license](LICENSE).

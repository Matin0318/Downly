**Title:** Downly – Fast Download Manager

**Short description:** Fast, ad-free downloads with queues, schedules and resume.

**Full description:**

Downly is a fast, open-source download manager for Android. It splits every file across several connections, resumes after any interruption, and never shows ads.

- Multi-connection downloads (up to 64 per file) that rebalance themselves, so no connection sits idle
- Multiple queues, each with its own schedule (any minute, chosen days, works with the app closed), speed limit, parallel limit and Wi-Fi-only rule
- An add window that detects the file name and size as soon as you paste a link
- HTTP(S), FTP, HLS (.m3u8) and DASH (.mpd) streams with a quality picker, and BitTorrent (magnet links and .torrent files)
- A built-in browser with tabs, bookmarks, an ad blocker and a list of the videos and files found on each page
- Site Grabber: pick files from a web page
- "Copy as cURL" support, so cookies and referer carry over
- HTTP and SOCKS5 proxy
- Checksum check (MD5, SHA-1, SHA-256)
- A file manager with "Open with" and a built-in video and audio player
- Finished files saved straight to your Downloads folder, or to a folder you choose
- A home-screen widget, a data-usage chart, and backup and restore
- English and Persian (right-to-left), light and dark themes, phones and tablets

No ads. No tracking. No account.

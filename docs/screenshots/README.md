# Screenshots

Put the screenshots used in the main README here. PNG files about 1080 px wide work well.

Suggested set:
1. `downloads-fa.png` – the Downloads tab in Persian, dark theme, with active downloads
2. `downloads-en.png` – the same in English, light theme
3. `queues.png` – the Queues tab
4. `browser.png` – the built-in browser with the media list
5. `settings.png` – Settings
6. `tablet.png` – the tablet layout with the side rail

To show them in the README, add lines such as `![Downloads](docs/screenshots/downloads-en.png)` in the section you like, for example right under the introduction.

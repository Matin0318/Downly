# تصویرها

تصویرهایی را که در README اصلی استفاده می‌شوند اینجا بگذارید. فایل‌های PNG با عرض حدود ۱۰۸۰ پیکسل مناسب‌اند.

مجموعهٔ پیشنهادی:
1. `downloads-fa.png` – تب دانلودها به فارسی، تم تیره، با دانلودهای فعال
2. `downloads-en.png` – همان به انگلیسی، تم روشن
3. `queues.png` – تب صف‌ها
4. `browser.png` – مرورگر داخلی با فهرست رسانه
5. `settings.png` – تنظیمات
6. `tablet.png` – چینش تبلت با نوار کناری

برای نمایش آن‌ها در README، خطی مثل `![Downloads](docs/screenshots/downloads-en.png)` را در هر بخشی که می‌خواهید اضافه کنید، مثلاً درست زیر مقدمه.
